## GigaFlow

**Местный низко-кодовый/но-коду low-code конструктор агентных пайплайнов. GigaChat + BGE-M3. Полностью оффлайн, кроме GigaChat API.**

### Переключение LLM-провайдеров

GigaFlow поддерживает несколько бэкендов для LLM:

| Провайдер | Как работает |
|-----------|-------------|
| **GigaChat** | Sber GigaChat API (облако) |
| **Локальный OpenAI** | LM Studio, Ollama, llama.cpp и др. через совместимый с OpenAI API на `localhost:5000` |
| **Auto** | Сначала пытается подключиться к локальному, если нет — автоматически использует GigaChat |

Смените провайдер в боковой панели. Нажмите **Тест соединения**, чтобы проверить оба бэкенда.

#### Настройка LM Studio
1. Запустите LM Studio → Загрузите модель → Запустите сервер
2. Установите порт на `5000`
3. GigaFlow автоматически находит его по адресу `http://127.0.0.1:5000/v1`
4. Выберите **Локальный (LM Studio)** в боковой панели

#### Настройка Ollama
```bash
ollama serve
# GigaFlow подключится по http://127.0.0.1:5000/v1
```

## Быстрый старт

```bash
cd gigaflow
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# Редактируйте .env — добавьте GIGACHAT_CREDENTIALS
python main.py
# Откройте http://127.0.0.1:8000
```

## Как пользоваться

### 1. Canvas — Создание пайплайнов
- Нажмите кнопки инструментов (Агент, Инструмент, Юрист, Цикл, Условие, RAG), чтобы добавить узлы
- Перетаскивайте узлы, держая за область тела (не за порты)
- Создание соединений: кликните на порт (маленький круг), перетащите к другому порту и отпустите
- **Проверка перед запуском**: каждый пайплайн проверяется:
  - Наличие входного и выходного узлов
  - Все не-входные узлы имеют входящие соединения
  - У агентов есть системные промпты
  - У инструментов выбраны нужные инструменты
- Нажмите **Запустить**, чтобы выполнить. Узел мерцает зеленым во время работы.
- Нажмите **Сохранить**, чтобы сохранить пайплайн на сервер

### 2. Чат — Разговор с GigaChat
- Введите сообщения, нажмите Enter
- Прикрепление файлов: кликните на бумажник → файл автоматически читается и отправляется в контексте
- Файлы также автоматически индексируются для RAG

### 3. Инструменты — Создание кастомных инструментов
- Пишите Python-код в редакторе
- Используйте декоратор `@gigaflow_tool` (см. `tools_library/example_tool.py`)
- Нажмите **Проверить** — GigaChat проверит код на ошибки
- Нажмите **Сохранить инструмент** — файл сохранится в `tools_library/`, watcher автоматически загрузит его
- Новые инструменты сразу появляются в выпадающих списках узлов Агента

### 4. RAG — Поиск по документам
- Перетащите файлы в зону для dropped (txt, md, pdf, docx, py, json, csv)
- BGE-M3 встроит их на GPU в FAISS
- Поиск естественным языком
- Включите "Использовать RAG" в конфигурации Агента для автоматического внедрения контекста

### 5. Юристы (Judges)
- Добавьте узел **Юрист** между Агентом и Выходом
- Установите критерии: например, "Точность формата JSON"
- Юрист вызывает GigaChat для оценки 0-10 и возвращает JSON `{score, reason, passed}`
- Используйте узел Условие после Юриста для разветвления по результату `passed`

## Расширенный: Агент, который пишет агентов

Пакет `file_tools.py` дает агентам доступ к файловой системе:

- `list_directory(path)` — сканировать структуру проекта
- `read_file(path)` — читать исходный код
- `save_file(path, content)` — создавать новые агенты/инструменты
- `analyze_folder_for_ui(folder_path)` — читать все файлы, возвращает превью для генерации UI

**Пример рабочего процесса:**
1. Чат: "Создайте нового агента, который суммиризирует PDF и сохраните его как `pdf_agent.py`"
2. GigaChat спланирует код
3. Агент вызывает `save_file` с сгенерированным Python
4. Watcher автоматически обнаруживает `pdf_agent.py` → новый инструмент появляется в Canvas мгновенно
5. Перетащите новый инструмент в пайплайн, подключите и запустите

**UI Generator Agent:**
1. Чат: "Создайте дашборд UI для папки `tools_library/`"
2. Агент вызывает `analyze_folder_for_ui("./tools_library")`
3. Получает все превью файлов
4. Генерирует HTML/CSS/JS дашборд
5. Вызывает `save_file("./frontend/static/generated_dashboard.html", ...)`
6. Вы можете открыть его прямо в браузере

## Архитектура

```
gigaflow/
├── main.py                    # FastAPI (127.0.0.1 только)
├── config.py                  # Настройки .env
├── backend/
│   ├── core/
│   │   ├── llm_manager.py     # GigaChat async + юристы + валидация кода
│   │   ├── pipeline_engine.py  # Движок выполнения графа
│   │   └── tool_watcher.py     # Hot-reload из tools_library/
│   ├── rag/
│   │   ├── vector_store.py     # BGE-M3 + FAISS (локальная GPU)
│   │   └── document_processor.py
│   └── api/routes.py           # REST + WebSocket
├── frontend/
│   ├── templates/index.html
│   └── static/{css,js}/
└── tools_library/             # Ваши инструменты (автозагрузка)
    ├── example_tool.py
    └── file_tools.py
```

## Советы для идеальной настройки

- **GPU**: BGE-M3 загружается на CUDA по умолчанию. Если GPU нет, измените `BGE_DEVICE=cpu` в `.env`
- **Шрифт**: Используется системный шрифтовой стек (без внешних загрузок). Выглядит локально на каждой ОС.
- **Размер Canvas**: Максимум 50 узлов ограничено в UI, чтобы избежать торможения браузера.
- **Безопасность**: Сервер прослушивает только `127.0.0.1`. Нет внешнего доступа.
- **Async**: Все вызовы LLM асинхронные со стримингом. UI остается отзывчивой во время длинных цепочек агентов.
